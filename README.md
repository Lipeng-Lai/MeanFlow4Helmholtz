# MeanFlow4Helmholtz

This repository implements conditional generative models for frequency-domain
Helmholtz scattered wavefields. It contains a matched GNO diffusion baseline
and an Improved Mean Flows model, both operating on factorized 70×70 data with
real and imaginary wavefield channels.

The commands below are run from the repository root.

## 1. Environment and data

The code requires Python with PyTorch, NumPy, SciPy, Matplotlib, and PyYAML.
Use the PyTorch build appropriate for the available CUDA device when training.

The generated data are expected in the following layout:

```text
dataset/
├── train/
│   ├── data/background.npy
│   ├── data/velocity.npy
│   └── label.npy
├── val/
├── test/
│   ├── data/
│   └── velocity_models_70x70/
└── velocity_models/
```

The factorized Helmholtz dataset is generated according to
[`configs/generate_helmholtz.yaml`](configs/generate_helmholtz.yaml):

```bash
python dataset/generate/generate_helmholtz.py \
    --config configs/generate_helmholtz.yaml
```

The configuration defines the frequencies, 70×70 grid, source positions,
absorbing boundary, numerical stencil, and dataset split. If the data are
already available, this step can be skipped.

## 2. Train the two experiments

The two experiments use separate configurations and write checkpoints below
`checkpoint/`.

### GNO diffusion baseline

```bash
python train.py --config configs/gno_ema999.yaml
```

### Improved Mean Flows

```bash
python train.py --config configs/meanflow_improved_ema999.yaml
```

The configurations define the data roots, model architecture, optimizer,
training duration, EMA decay, validation schedule, and sampling settings.
Training resumes automatically from the latest checkpoint in the configured
output directory when one is present.

Convenience wrappers are also available:

```bash
bash scripts/gno.sh
bash scripts/meanflow_improved.sh
```

Set `CUDA_VISIBLE_DEVICES` before invoking a command to choose a GPU, for
example:

```bash
CUDA_VISIBLE_DEVICES=0 python train.py \
    --config configs/meanflow_improved_ema999.yaml
```

## 3. Inference and evaluation

Evaluate the best EMA checkpoint on the test split with:

```bash
python evaluate.py \
    --config configs/gno_ema999.yaml \
    --split test

python evaluate.py \
    --config configs/meanflow_improved_ema999.yaml \
    --split test
```

Use `--split val` for validation data. A specific checkpoint can be supplied
with `--checkpoint`:

```bash
python evaluate.py \
    --config configs/meanflow_improved_ema999.yaml \
    --split test \
    --checkpoint checkpoint/meanflow_improved_ema999/model_best.pth
```

Evaluation reports relative \(L_2\) error and grouped metrics in the experiment
`runlog.txt`.

## 4. Reproduce the paper figures

All plotting scripts are under [`paper_plot/`](paper_plot/). They should be
run from the repository root after the required data and checkpoints are
available.

### Method and training figures

```bash
python paper_plot/01_method/plot_method.py
python paper_plot/02_loss/plot_loss.py
```

### In-distribution comparison figures

```bash
python paper_plot/03_CurveVel_A/plot_curvevel_a.py
python paper_plot/03_CurveVel_A/plot_residual_steps.py

python paper_plot/04_CurveFault_A/plot_curvefault_a.py
python paper_plot/04_CurveFault_A/plot_residual_steps.py

python paper_plot/05_Marmousi/plot_marmousi.py
python paper_plot/05_Marmousi/plot_residual_steps.py

python paper_plot/06_Overthrust/plot_overthrust.py
python paper_plot/06_Overthrust/plot_residual_steps.py
```

Use `--component imag` with scripts that expose the option to render the
imaginary wavefield component instead of the real component.

### Out-of-distribution frequency figure

The Overthrust OOD-frequency script uses the third source and evaluates
8–17 Hz. Frequencies not stored in the factorized test set are regenerated by
the Helmholtz solver.

```bash
python paper_plot/07_ood_freq/plot_ood_freq.py --device cuda
```

The outputs are:

```text
paper_plot/07_ood_freq/sampling_curves_overthrust.png
paper_plot/07_ood_freq/sampling_curves_overthrust.pdf
```

### Efficiency figure

```bash
python paper_plot/08_effiency/plot_multifrequency_efficiency.py \
    --device cuda
```

This benchmark runs numerical solves and model timing measurements and can
take substantially longer than the other plotting scripts.

## Repository layout

```text
configs/       Dataset, GNO, and Improved Mean Flows configurations
diffusion/     Gaussian diffusion implementation and samplers
meanflow/      Mean Flows objectives and samplers
models/        Conditional neural network architectures
paper_plot/    Reproducible paper-figure scripts and exported figures
scripts/       Training convenience wrappers
utils/         Data loading, normalization, metrics, and runtime utilities
train.py       Training entry point
evaluate.py    Validation/test evaluation entry point
```

Datasets, checkpoints, caches, and logs are intentionally excluded from Git
tracking by `.gitignore`. They should be generated or downloaded separately.
